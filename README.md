# chem-dorm

Chemistry-themed room tower defense for macOS. Godot 4.7.2 Standard + GDScript.
1 player + 5 ally bots vs 1 AI invader. Design lock: `DESIGN.md`.

## Local

```bash
cd /Users/a0000/Developer
git clone git@github.com:9947447-alt/chem-dorm.git
cd chem-dorm
```

Open the folder in Godot 4.7.2 (Standard, not .NET). First playable slice is a grid floor + claim-room loop only.

## 怎么玩

开游戏：终端 `godot --path .`，或 Godot 编辑器打开本目录后按 F5。

移动：W/A/S/D，方向键也可以。

占房：走到房间里的起步矿格子上，自动占房。一房只能被一人占。

选格：左键点任意一格（走廊、空地、建筑、门都会出菜单）。点菜单项才建造或升级并扣费。点菜单外或按 Esc 关闭，关闭不扣费。不能做的项是灰的，后面写原因。

矿：点自己房间空格选矿种。建好后可点击矿山原地升级（铁->钨->钼->硫->锑->金->铀）。

厂：点自己房间空格，菜单里选化工厂。再点这座厂，菜单里选升级。

炮：点自己房间空格，菜单里选硅酸炮台。随升级射程变大，在射程范围内可全向攻击。碳酸 V 时菜单出现换线 A / 换线 B。

高科技：
- 取款机：消耗 1000 金币与 40 原料，每周期稳定产出 200 高额金币。
- 粒子加速器：消耗 120 原料，使所在房间炮台攻速提升 50%（射击间隔缩短至 1/1.5）。

门：开局自带持续自动回血；回血能力随升级严格增强（30 档严格单调递增）；点门格升级舱门，每次升级门血量立即回满。最高等级 Lv 15 敌人经过装甲扣减后仍具有净正向 DPS，确保终局可破防攻入。

拆除：点击非起步矿的任意己方建筑（矿山、化工厂、炮台、高科技设备），均可拆除并回收建造资源的 50%。

起步矿：点起步格，菜单里选升级起步矿（起步矿受保护不可拆除）。

地图与视角：全图包含 10 个大小不同、错落布局的宿舍；开局 3 秒准备冻结期，盟友随机挑选房间入驻；摄像机默认采用第一人称近距平滑跟随主角移动。主角到达房间起步矿后解锁鼠标拖拽屏幕自由浏览全图，走动（WASD）时自动平滑回正。

跳字：格子上「金币 +N」是起步矿或产金钱矿刚入账；「原料 +N」是化工厂刚入账；红色「-N」为敌人受创；橙色「-N」为舱门受创；绿色「+N」为回血台回血。约 0.8 秒后消失。

血条：舱门血条与敌人头顶血条均加大加厚展示，舱门与起步矿掉血变短，门破后为空条。

赢：炮台把入侵者 HP 打到 0。

输：自己房间的起步矿被拆光，或场上全部宿舍起步矿全灭。

重开：任意胜负结算后，按 R 键一键重新开始对局。

没有：暂停键、数字键建造、空格。
